# Contributing

## Scope

Этот репозиторий является демонстрационным проектом. Изменения должны усиливать одну из трёх задач:

- наглядность UI
- понятность LLM/SEO workflow
- качество локального демо-запуска

## Перед изменениями

Убедитесь, что вы понимаете текущее поведение:

- встроенные данные лежат в `src/data.ts`
- runtime-генерация лежит в `scripts/pipeline-demo.mjs`
- итоговый UI должен оставаться пригодным для демонстраций и скриншотов

## Рекомендации по изменениям

- не добавляйте backend-зависимости без явной необходимости
- не превращайте демо в тяжёлую production-систему без отдельной архитектурной задачи
- сохраняйте связность терминов между UI, README и demo dataset
- если меняете этапы пайплайна, обновляйте документацию
- если меняете env vars или команды запуска, обновляйте `README.md`

## Локальная проверка

Перед коммитом желательно выполнить:

```bash
npm install
npm run lint
npm run build
```

Если вы меняли demo pipeline:

```bash
npm run pipeline:demo
```

## Pull Requests

В PR полезно описать:

- что именно поменялось
- зачем это нужно
- влияет ли изменение на UI, demo dataset или запуск
- нужно ли обновлять скриншоты
